## Как посмотреть постер

Открой [`poster/poster.html`](poster/poster.html) двойным кликом — он откроется в браузере и сам подгонится под ширину окна. Интернет нужен только для загрузки шрифтов.

## Как получить PDF

**Вариант 1 — скриптом (рекомендуется).**

Windows, в PowerShell из корня репозитория:
```powershell
powershell -ExecutionPolicy Bypass -File poster\make-pdf.ps1
```

macOS / Linux / Git Bash:
```bash
bash poster/make-pdf.sh
```

Скрипт найдёт Chrome или Edge, отрендерит и положит `Aktobe_Poster_A1.pdf` в корень.

**Вариант 2 — вручную.** Открой `poster/poster.html` в браузере → `Ctrl`+`P` → «Сохранить как PDF», бумага **A1**, поля **«Нет»**, галочка **«Фоновая графика»** обязательно.

**Проверка размера.** В свойствах PDF должно быть 594 × 841 мм (1684 × 2384 pt), одна страница.

## Как править

Весь постер — один файл `poster/poster.html`. Блоки расставлены абсолютными координатами **в миллиметрах**, поэтому положение на листе предсказуемо.

```html
<div style="left:20mm;top:275mm;width:554mm;height:195mm">…</div>
```

Карта координат всех блоков — в [docs/02-poster-content.md](docs/02-poster-content.md), раздел 1.

### Что где искать в файле

| Нужно поменять | Ищи в файле |
|---|---|
| Цвета, размеры шрифтов | блок `:root{…}` в начале `<style>` |
| Текст любого блока | комментарии `<!-- ============ 01 · … ============ -->` |
| Данные графика эвакуации | `<script>` внизу, переменная `P` |
| Изображения и подписи | блок `04 · WHAT FOLLOWED` |

### Подводные камни

1. **Правило `.poster div{position:absolute}`.** Все `<div>` внутри постера позиционируются абсолютно. Если нужен элемент в обычном потоке — пиши `style="position:static"` прямо в атрибуте (инлайн-стиль перебивает правило) либо используй класс `.bul`.
2. **Инлайновые теги.** `<b>`, `<em>`, `<u>`, `<br>`, `<img>`, `<span>` уже выведены из абсолютного позиционирования отдельным правилом. Если добавляешь новый инлайновый тег — допиши его в этот список, иначе текст сложится в одну точку.
3. **Кодировка.** Файл в UTF-8, в начале стоит `<meta charset="utf-8">`. Не сохраняй в другой кодировке — превратится в кракозябры.
4. **Изображения** подключаются как `../images/имя.jpg`. Класс `.crop` заполняет бокс с обрезкой краёв, без него изображение показывается целиком.

### Как проверить, что ничего не разъехалось

Открой файл в браузере, нажми `F12` → Console и вставь:

```js
(() => {
  const p = document.getElementById('poster'), pr = p.getBoundingClientRect();
  const bad = [];
  p.querySelectorAll('div,svg,img').forEach(el => {
    const r = el.getBoundingClientRect();
    if (r.bottom > pr.bottom + 1 || r.right > pr.right + 1)
      bad.push((el.textContent || el.tagName).trim().slice(0, 40));
  });
  console.log(bad.length ? bad : 'всё внутри листа');
})();
```

Выведет список элементов, вылезших за границы A1, или сообщение, что всё в порядке.

## Суть кейса за одну минуту

27–29 марта 2024 в Актюбинское водохранилище пришло **200 млн м³** воды — 80 % его проектного объёма за двое суток. Плотина построена в 1988 году и ни разу не реконструировалась.

У операторов было два варианта:

- **RELEASE** — сбрасывать сразу. Плотина в безопасности, но вода идёт на посёлки, где люди ещё дома и не предупреждены.
- **HOLD** — держать воду. Люди внизу в безопасности, но уровень поднимается выше проектного у 36-летнего сооружения.

Они не выбрали ни то, ни другое чисто: **накопили 15 млн м³ сверх проектной мощности**, чтобы выиграть часы на эвакуацию, и только потом подняли сброс до 1 000 м³/с.

Итог: 689 затопленных дачных домов, 2 870 эвакуированных, **ноль погибших**.

Между официальным опровержением опасности и приказом эвакуироваться прошло **23 часа 25 минут**.

Обе ключевые формулировки — про 15 млн м³ и про причинную связь сброса с затоплением — взяты из официальных релизов правительства РК, не из СМИ. См. [docs/01-research.md](docs/01-research.md), раздел 1.

## Что нельзя утверждать на постере

Коротко (подробно — [docs/01-research.md](docs/01-research.md), раздел 5):

1. Что Ринат Шауенов **лично** отдал приказ на сброс — ни одного документа.
2. Правовые нормы из приказов 2025 года — они приняты **после** событий.
3. Что власти солгали, чтобы избежать паники — мотив не установлен.
4. Что жителей предупредили за 15 минут — это опыт одной семьи, а не общегородской факт.
5. Любые цифры максимальной пропускной способности сооружения — нет надёжного источника.

## Что ещё можно добить

1. **Точное время открытия второго затвора.** В открытых источниках его нет — проверено сплошным поиском. Запрос через [egov.kz](https://egov.kz) в Актюбинский филиал РГП «Казводхоз».
2. **Декларация безопасности ГТС** — там пропускная способность, тарировочные кривые и готовая карта зон затопления.
3. **Фотографии в большем разрешении** для `general_photo_1` (152 dpi) и `general_photo_2` (170 dpi) — сейчас на нижней границе типографского минимума.

Даже отказ на запрос — цитируемый документ, подтверждающий проблему прозрачности.
